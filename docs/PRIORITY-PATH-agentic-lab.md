# Priority path - Agentic AI Lab entry (September 2026)

Source deck: `it-vocab` (1516 sentences, 15 tiers). This file selects **179** of them,
which are tiers 1-5 of `agentic-lab`. Tiers 6-12 are authored in the deck itself - a
self-introduction set and a team-vocabulary set - and this file does not specify them.

## Why this order

Tier numbers below are `it-vocab` tiers, not `agentic-lab` ones.

The tempting move is to grind Tier 9 (AI & Agents) because it matches the new team's
subject matter. That is the worst use of a short runway. Tier 9 is mostly katakana English
you already read fluently: エージェント, プロンプト, モデル, コンテキスト, トークン,
ハルシネーション, ベンチマーク, ガードレール, リンター, フック. Studying it feels
productive and teaches almost nothing.

The thing that actually breaks a conversation is losing the thread mid-sentence with no move
to recover. So recovery phrases come first, meeting structure second, and the plain-form
register you will actually hear third. Subject-matter vocabulary comes last because it is the
part you can already guess.

Not included, deliberately: Tier 6 (presentations), Tier 7 (interview keigo),
Tier 14 (business email), Tier 15 (written tickets). Wrong register for walking in the door.

deck because they keep a conversation alive after comprehension has already failed. If you
learn nothing else before September, learn these.
